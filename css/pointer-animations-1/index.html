概要

指定された範囲でのポインターの位置に連動するアニメーションを 作成するためのCSSプロパティとAPIを定義する。この範囲は ビューポートまたは要素の境界ボックスを基準にできる。

CSS は、構造化文書 （HTMLやXMLなど）を画面、紙面などに 描画する方法を記述するための言語である。

1. 導入

この仕様は、 アニメーションの進捗を駆動する仕組みを定義する。 その進捗は、指定された範囲内でのポインター位置の進み具合に基づく。 この ポインター駆動アニメーション は、ポインター位置に基づくタイムラインを使用し、 時間ではなく長さを基準とする。この点で、 動作や概念は スクロール駆動アニメーションに似ている。 このモジュールは、Web Animations APIを基盤とする命令型APIと、 CSS Animationsを基盤とする 宣言型APIの双方を提供する。 [CSS-ANIMATIONS-2] [WEB-ANIMATIONS-1]

1.1. 他の仕様との関係

Web Animations [WEB-ANIMATIONS-1] は、 Webプラットフォームにおけるアニメーションの抽象的な概念モデルを定義する。 このモデルには アニメーション 、その タイムライン、 および関連するプログラミングインターフェースが含まれる。 この仕様はWeb Animationsのモデルを拡張する。 ポインター進捗タイムライン を定義し、それによって アニメーション の進捗を駆動して ポインター駆動アニメーションを実現する。

この仕様は、 これらの概念を扱うプログラミングインターフェースに加え、 これらの概念を CSS Animations [CSS-ANIMATIONS-1]に適用するCSSプロパティも導入する。 これらのCSSプロパティの挙動がプログラミングインターフェースを用いて 記述される場合であっても、 ユーザーエージェント がスクリプトをサポートしない場合は、 基礎となるプログラミングインターフェースが存在するかのように CSS機能を実装することで、 この仕様に適合できる。

この仕様は、 Scroll-Driven Animationsモジュール [SCROLL-ANIMATIONS-1] が進捗に基づくタイムラインと アニメーションを指定するために導入した概念や機能をもとにしている。

CSSにおける他のほとんどの操作と同様に（ セレクター の照合を除く）、 この仕様の機能は 平坦化された要素ツリーに対して作用する。

1.2. 値の定義

この仕様は CSSのプロパティ定義の規約 に従う。 [CSS2] また、 値定義構文 を使用する。 [CSS-VALUES-3] この仕様で定義されていない値型は CSS Values & Units [CSS-VALUES-3]で定義されている。 他のCSSモジュールとの組み合わせにより、これらの値型の定義が拡張される場合がある。

プロパティの定義に挙げられている固有の値に加え、 この仕様で定義されるすべてのプロパティは、 CSS全体キーワード もプロパティの値として受け付ける。 読みやすくするため、これらは各定義で明記していない。

2. ポインター進捗タイムライン

ポインター進捗タイムライン とは、特定の軸に沿った 要素の 主要ボックス 上でのポインター位置の進捗に連動するタイムラインである。

ポインター範囲 とは、 要素の 主要ボックス を ポインター進捗タイムラインの軸に沿って測った大きさである。

ポインターオフセット とは、ポインターの 要素の ポインター範囲の始点を基準とする位置である。 この位置は offsetX と offsetY によって定義される。 [CSSOM-VIEW-1] 始端の ポインターオフセット は進捗0%を、 終端の ポインターオフセット は進捗100%を表す。

ポインター進捗タイムライン は、 animation-timeline において pointer() 関数記法 を用いた無名の参照と、名前による参照が可能である（ Scroll-driven Animations § 4.2「名前付きタイムラインのスコープと探索」を参照）。 名前で参照するには、先に pointer-timeline プロパティを使って宣言する。 Web Animations APIでは、 PointerTimeline オブジェクトによって無名で表現できる。

2.1. ポインター進捗タイムラインの範囲

ポインター進捗タイムライン は、次の 名前付きタイムライン範囲を定義する。

fill
ポインター進捗タイムラインの全範囲を表す。

  • 進捗0%は、ポインターが 要素の 始端側 パディング辺 （ 主要ボックスの辺）上にある位置を示す。

  • 進捗100%は、ポインターが 要素の 終端側 パディング辺 （ 主要ボックスの辺）上にある位置を示す。

fit
fillと同じ大きさの範囲を表すが、 進捗0%と100%の点は、 animation-range-center プロパティの値に従ってずらされ、 進捗50%の点は範囲の中央に留まる。
cover
ポインター進捗タイムライン のうち要素の 主要ボックス を完全に覆う、可能な限り大きい範囲を表す。 animation-range-center プロパティの値に従い、次のようになる。

  • 進捗50%の点から要素の 始端側 パディング辺 までの距離が、 進捗50%の点から要素の 終端側 パディング辺までの距離よりも大きい場合、 進捗0%の点は要素の 始端側 パディング辺にあり、 進捗100%の点は進捗50%の点から同じ距離だけ 反対側に離れた位置にある。

  • それ以外の場合、進捗100%の点は要素の 終端側 パディング辺にあり、進捗0%の点は進捗50%の点から同じ距離だけ 反対側に離れた位置にある。

contain
完全に包含される、可能な限り大きい範囲を表す。 包含するのは要素の 主要ボックス であり、範囲は animation-range-center プロパティの値に従って、次のようになる。

  • 進捗50%の点から要素の 始端側 パディング辺 までの距離が、 進捗50%の点から要素の 終端側 パディング辺までの距離よりも小さい場合、 進捗0%の点は要素の 始端側 パディング辺にあり、 進捗100%の点は進捗50%の点から同じ距離だけ 反対側に離れた位置にある。

  • それ以外の場合、進捗100%の点は要素の 終端側 パディング辺にあり、進捗0%の点は進捗50%の点から同じ距離だけ 反対側に離れた位置にある。

図を挿入する。

いずれの場合も、 書字モード は 始端 と 終端 の辺を解決するために使用される。 ここで使う 書字モード は、該当する 主要ボックスの書字モードである。 変形 は無視されるが、 相対 および 絶対 位置指定は 考慮される。

2.3. 無名のポインター進捗タイムライン

2.3.1. pointer() 記法

pointer() 関数記法は、 <single-animation-timeline> 値として animation-timeline で使用でき、 ポインター進捗タイムラインを指定する。 構文は次のとおり。

<pointer()> = pointer( [ <source> || <axis> ]? )
<axis> = block | inline | x | y
<source> = root | nearest | self

既定では、 pointer() は インライン軸 （要素自身の ポインター範囲の軸）を参照する。 引数は、この探索を次のように変更する。

block
進捗の測定に、 ブロック軸 （ ポインター範囲の軸）を使用するよう指定する。
inline
進捗の測定に、 インライン軸 （ ポインター範囲の軸）を使用するよう指定する。 （既定値。）
x
進捗の測定に、 水平軸 （ ポインター範囲の軸）を使用するよう指定する。
y
進捗の測定に、 垂直軸 （ ポインター範囲の軸）を使用するよう指定する。
self
要素自身の 主要ボックス を ポインター範囲として使用するよう指定する。 （既定値。）
nearest
最も近い要素の 親ボックス を ポインター範囲として使用するよう指定する。
root
ルート要素の 主要ボックス を ポインター範囲として使用するよう指定する。

pointer() を使用するたびに、 PointerTimeline の個別のインスタンスがWeb Animations APIで対応する。 複数の要素が pointer() を使い、同じ引数で 同じ ポインター範囲 を参照する場合も同様である。

2.3.2. PointerTimeline インターフェース

enum PointerAxis {
  "block",
  "inline",
  "x",
  "y"
};

dictionary PointerTimelineOptions {
  Element? source;
  PointerAxis axis = "block";
};

[Exposed=Window]
interface PointerTimeline : AnimationTimeline {
  constructor(optional PointerTimelineOptions options = {});
  readonly attribute Element? source;
  readonly attribute PointerAxis axis;
};

PointerTimeline は、 AnimationTimeline の一種であり、 ポインター進捗タイムラインを表す。 アニメーションを関連付けるには、 Animation コンストラクターまたは animate() メソッドにこれを渡す。 これによりアニメーションが ポインター進捗タイムラインに関連付けられる。

source, 型： Element、読み取り専用、null許容

その ポインターオフセット が タイムラインの進捗を駆動する要素。

axis, 型： PointerAxis、読み取り専用

タイムラインの進捗を駆動する軸。 前述の <axis>の値の定義を参照。

継承する属性：

  2. source （ timeline の属性）を次の値に設定する：

    source メンバーが options に存在する場合、

2.4. 名前付きポインター進捗タイムライン

ポインター進捗タイムライン は宣言的に定義することもできる。 その場合、名前のスコープ内にある要素は、その名前で タイムラインを参照できる （ Scroll-driven Animations § 4.2「名前付きタイムラインのスコープと探索」を参照）。

このような 名前付きポインター進捗タイムライン は、 協調値リスト （ pointer-timeline-* プロパティ群から構成される）で宣言される。 これらのプロパティは、 協調リストプロパティ群 を形成し、 pointer-timeline-name を 協調リスト基底プロパティとする。 CSS Values 4 付録A「協調リスト値プロパティ」を参照。

2.4.1. ポインター進捗タイムラインの命名： pointer-timeline-name プロパティ

名前： pointer-timeline-name
値： [ none | <dashed-ident> ]#
初期値： none
適用対象： すべての要素
継承： なし
百分率： 該当なし
算出値： キーワード none 、またはリスト（項目は CSS識別子）
正規順序： 文法による
アニメーション型： アニメーション不可

名前付きポインター進捗タイムライン のうち、この要素に関連付けられるものの名前を指定する。

2.4.2. ポインター進捗タイムラインの軸： pointer-timeline-axis プロパティ

名前： pointer-timeline-axis
値： [ block | inline | x | y ]#
初期値： block
適用対象： すべての要素
継承： なし
百分率： 該当なし
算出値： 指定したキーワードのリスト
正規順序： 文法による
アニメーション型： アニメーション不可

名前付きポインター進捗タイムライン のうち、この要素の 主要ボックスに由来するものの軸を指定する。 この要素に 主要ボックス が存在しない場合、 対応する 名前付きポインター進捗タイムライン は 非アクティブになる。

値は pointer()で定義されているものと同じである。

2.4.3. ポインタータイムラインの一括指定： pointer-timeline 一括指定プロパティ

名前： pointer-timeline
値： [ <'pointer-timeline-name'> <'pointer-timeline-axis'>? ]#
初期値： 個別プロパティを参照
適用対象： すべての要素
継承： 個別プロパティを参照
百分率： 個別プロパティを参照
算出値： 個別プロパティを参照
アニメーション型： 個別プロパティを参照
正規順序： 文法による

このプロパティは、 一括指定 であり、 pointer-timeline-name と pointer-timeline-axis を単一の宣言で設定する。

付録A：アニメーション範囲の中心の設定

この節はCSS-ANIMATIONS-2およびWEB-ANIMATIONS-2に移すべきである。

Scroll-driven Animations の「アニメーションをタイムライン範囲に結び付ける」節では、 一連のアニメーションキーフレームを アニメーション結合範囲に結び付ける概念を導入している。これにより、 アニメーションの進捗を表す単一の線形範囲が作成される。

ポインター駆動アニメーションでは、新たに、 アニメーションの焦点（進捗50%の点）を 定められた位置に変更できる。この位置は アニメーション結合範囲の既定の中央とは異なってよい。 この設定には animation-range-center プロパティを使用する。

アニメーション範囲の中心の基準要素 とは、その 主要ボックス を基準範囲として、 アクティブ範囲の中心を計算する要素である。 この要素は <timeline-range-center-subject> 値型で表され、 次のいずれかを表す CSS識別子 によって 指示される。

source
その ポインターオフセット がタイムラインの進捗を駆動する要素。
target
アニメーションが適用される要素。

進捗50%の点が進捗0%の点よりも小さい位置にある場合や、 進捗100%の点よりも大きい位置にある場合がある。その場合、 アニメーション結合範囲 は進捗50%の点で打ち切られる。

アニメーションのタイムライン範囲の中心の指定： animation-range-center プロパティ

名前： animation-range-center
値： [ normal | [ <length-percentage> | <timeline-range-center-subject> <length-percentage>? ] ]#
初期値： normal
適用対象： すべての要素
継承： なし
百分率： 指定されたタイムライン範囲の中心の基準要素の対応する寸法が基準となる。基準要素が指定されていない場合は始点が基準となる： アニメーション結合範囲
算出値： リスト。各項目はキーワード normal またはタイムライン範囲の中心の基準要素と長さ・百分率値の組である
正規順序： 文法による
アニメーション型： アニメーション不可

アニメーション結合範囲の中心点を指定する。 すなわち、アニメーション範囲における進捗50%の点を指定する。

各値の意味は次のとおり。

normal
アニメーションの アクティブ区間 の進捗50%の点は、 アニメーション結合範囲の中央となる。
<length-percentage>
アニメーションの アクティブ区間 の進捗50%の点は、 タイムライン 上において、 アニメーション結合範囲の始点から測った指定の位置となる。 百分率は アニメーション結合範囲の大きさを基準とする。
<timeline-range-name> <length-percentage>?
アニメーションの アクティブ区間 の進捗50%の点は、 始端側 パディング辺 を基準とする指定の位置となる。 その辺は、指定された アニメーション範囲の中心の基準要素の 主要ボックスの辺である。 <length-percentage> が省略された場合、 既定値は50%である。

テスト

この仕様の内容に関連するテストは、 このような「テスト」ブロックに記載してよい。 この種のブロックはすべて非規範的である。

    適合クラス

    この仕様への適合性は、 次の3つの適合クラスについて定義される。

    スタイルシート
    CSS スタイルシート。
    レンダラー
    UA のうち、スタイルシートの意味論を解釈し、 それを使用する文書を描画するもの。
    オーサリングツール
    UA のうち、スタイルシートを作成するもの。

    スタイルシートがこの仕様に適合するのは、 このモジュールで定義される構文を使ったすべての文が、 一般的なCSS文法と、このモジュールが定義する 各機能の個別の文法に照らして妥当である場合である。

    レンダラーがこの仕様に適合するのは、 スタイルシートを関連仕様に従って解釈するだけでなく、 この仕様のすべての機能を正しく構文解析し、 その結果に従って文書を描画することで、 それらの機能をサポートする場合である。ただし、 機器の制約のためUAが文書を正しく描画できない場合でも、 UAが不適合となるわけではない。（例えば、 モノクロモニターでのカラー描画はUAに求められない。）

    オーサリングツールがこの仕様に適合するのは、 作成するスタイルシートが、 一般的なCSS文法とこのモジュールの各機能の個別文法に照らして構文的に正しく、 このモジュールが定めるスタイルシートへの他の適合要件も すべて満たす場合である。

    部分的な実装

    作者が前方互換性のある構文解析規則を利用して 代替値を指定できるようにするため、CSSレンダラーには次の規則が 必須である。 サポートが十分でない構文は無効とし（ 無視する のが適切な場合）、対象にはアットルール、プロパティ、プロパティ値、キーワード、 その他の構文要素が含まれる。 特にUAは、以下を選択的に行っては ならない 。 複数の値を持つ単一のプロパティ宣言の中で、サポートしない構成値だけを無視し、 サポートする値を採用すること。いずれかの値が無効であれば （サポートされない値は無効としなければならない）、 CSSでは宣言全体を無視する必要がある。

    不安定な機能および独自機能の実装

    将来の安定したCSS機能との衝突を避けるため、 CSSWGは、 ベストプラクティスに従う ことを推奨する。これは、 不安定な 機能およびCSSの 独自拡張 を実装する場合に適用される。

    非実験的な実装

    仕様が勧告候補の段階に達すると、 非実験的な実装が可能となる。実装者は、 CR段階の機能について、仕様どおりに正しく実装されていることを 実証できる場合、接頭辞なしの実装を公開すべきである。

    実装間でCSSの相互運用性を確立し維持するため、 CSS作業部会は、非実験的なCSSレンダラーに対して、 CSS機能を接頭辞なしで実装して公開する前に、実装報告書 （必要であれば、その報告書に用いたテストケースも）を W3Cへ提出するよう求める。W3Cに提出されたテストケースは、 CSS作業部会によるレビューと 修正の対象となる。

    テストケースおよび実装報告書の提出について詳しくは、 CSS作業部会のウェブサイト https://www.w3.org/Style/CSS/Test/を参照。 質問は、 public-css-testsuite@w3.org メーリングリストに送ること。
